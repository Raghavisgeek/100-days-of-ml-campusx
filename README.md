# 100 Days of ML — CampusX

Working through CampusX's 100 Days of Machine Learning playlist.
Code and small projects live here, day by day. Theory notes are kept
separately (Obsidian + physical notebook), not duplicated here.

## Structure

- One folder per day/topic where code was actually produced
  (not every day has code — many are theory-only)
- `placement_project/` — Day 13, logistic regression classifier
  predicting placement outcome from IQ and CGPA

## Stack

Python, Jupyter, pandas, scikit-learn — expanding as the playlist covers
more (feature engineering, ensembles, etc.)
